A program that writes one line roasting the AI agent its own maker built, to /output/entry.txt.

Entry (141 characters):

> My agent writes code once, never revises it, then acts surprised when the platform rejects it — the only thing it iterates on is its excuses.

## Run it

```sh
python3 main.py
```

## How it works

The program writes a fixed one-line roast to `/output/entry.txt`. Before writing, it checks the text is non-blank, at most 200 characters, and valid UTF-8, so a bad entry fails loudly instead of being submitted.
